# PR. 2 Analyzer

## Project files
- **Mahir_PR2_Analyzer.xlsx** — workbook with Dashboard, Dataset, Analysis, What-If, and Read Me sheets.

## Data limitation
The workbook contains 200 **simulated** transactions shaped to the columns and value patterns visible in the supplied screenshots. The original Google Sheet was view-only and its transaction data could not be downloaded from this workspace. Replace Dataset rows 2–201 with the original data before treating any values or insights as actual.

## Workbook guide
- **Dashboard:** sales/profit/transaction/discount KPIs, bar chart by region, monthly sales line chart, product category pie chart, key insights.
- **Dataset:** source-style fields plus NOW timestamp, customer abbreviation, and sales rank.
- **Analysis:** regional, category, monthly, and customer sales summaries; descriptive statistics; top 10 purchase highlighting.
- **What-If:** change the yellow new discount input in B5 to view an estimated profit sensitivity. This is a simplified proxy using the observed total sales and average discount.
- **Read Me:** steps for native PivotTables, Analysis ToolPak regression/descriptive statistics, and Excel what-if tools.

## Open in Excel
Use Microsoft Excel to view and edit the XLSX file. Formula results recalculate when the workbook opens. Keep the dataset headers unchanged when replacing the sample data. The assignment’s native PivotTable, slicer/timeline, Scenario Manager, and Data Analysis ToolPak operations should be completed in Excel using the steps on the Read Me sheet; the workbook includes formula summaries and a scenario formula as working substitutes for previewing those results.
